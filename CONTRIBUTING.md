# Contributing

## Ветки

Формат: `<type>/<short-description>`

Примеры:
- `feature/add-habit-creation`
- `fix/streak-calculation`
- `chore/update-dependencies`

Типы: `feature`, `fix`, `chore`, `docs`, `refactor`, `test`.

## Коммиты (Conventional Commits)

Формат: `<type>: <description>`

Примеры:
- `feat: add habit creation endpoint`
- `fix: correct streak calculation for weekends`
- `docs: update API examples in README`
- `test: add integration tests for habits`

## Pull Requests

1. Создай ветку от свежего `main`
2. Делай коммиты с осмысленными сообщениями
3. Открой PR, укажи `Closes #<issue-number>`
4. Дождись ревью от партнёра
5. После approve — squash and merge
6. Удали ветку
